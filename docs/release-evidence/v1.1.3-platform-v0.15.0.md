## Migration boundaries

Store consumes the characterized shared HTTP/security response, timezone/date,
Stripe transport, Wrangler inventory, KV transformation, checksum, command
result, and provider-evidence primitives through thin local adapters. Store
continues to own its default private origin, Stripe API version and User-Agent,
catalog, checkout, order/inventory truth, fulfillment, routes, storage,
credentials, provider calls, builds, deployment, and rollback.

Payment-event and reconciliation lease identifiers now use Platform's Web
Crypto token primitive and fail closed instead of falling back to
`Math.random()`. The Platform submodule contains no Store credentials,
environment IDs, customer data, product content, or deployment authority.
