# Store v1.1.5 / Platform cryptographic adoption evidence

## Immutable input

- Previous Store release: `v1.1.4`.
- Platform remains pinned to immutable `v0.15.0` commit
  `2e79a8d70cb6d30805ea141e53d32f9387441756`.
- Shared implementation remains `@dustwave/worker-core` `0.6.0`; this release
  consumes an already published module and does not mutate Platform.

## Characterized boundary

Store admin authentication imports SHA-256, HMAC-SHA-256, high-entropy tokens,
cookie parsing, email normalization, and constant-work string equality from
the pinned Platform source. A one-line Store adapter retains the existing
`secret, data` HMAC call order.

Store continues to own login-token and cookie formats, the shorter
order-notification login/session policy, session and CSRF records, origin
checks, roles and scopes, routes, KV storage, credentials, deployment, and
rollback. Platform receives no Store identifiers, secrets, customer data,
catalog content, or deployment authority.
