## Local Podman Limitation

The local full `npm run release:smoke` reached and passed pre-merge phases 1–9. Its initial cold Worker-volume install required seven minutes because registry downloads of Wrangler, Miniflare, and native binaries were unusually slow. After the exact lock was warmed and hash-stamped, the unchanged security phase passed under its normal 60-second readiness budget.

Pre-merge phase 10 then stopped before browser execution while Podman pulled the newly selected Playwright `1.62.0` image. Podman's image store returned `readlink .../overlay: invalid argument` followed by `server probably quit: unexpected EOF`. No Playwright assertion ran or failed. The remaining non-Podman release phases were rerun together and passed as recorded above. The protected GitHub Merge Smoke on the final head is therefore the required clean-runner browser and integration evidence; this local infrastructure failure is not represented as a complete release-smoke pass.

The optional VoiceOver/Whisper transcript was not requested or supplied. Automated accessibility/browser evidence must pass in protected CI, but it is not represented as a real assistive-technology session.

## Ethical Review

- **Money and inventory:** Store remains server-authoritative for cart validation, totals, tax, shipping, reservation, confirmation, and historical order prices. Shared helpers cannot initiate or recover a charge and do not create a second inventory authority.
- **Customer data and access:** No new customer-data family, provider, retention period, credential store, or public administrative route is introduced. Shared admin primitives preserve Store's authenticated, CSRF-protected, private/no-store boundary and fail closed through Store-owned adapters.
- **Messaging and automation:** No new transactional or promotional send path is introduced. Order truth, fulfillment state, and notification retries remain separate.
- **Accessibility and localization:** The admin dirty-action change preserves button state, labels, disabled policy, focus behavior, and Store-owned English/Spanish copy. The QR implementation remains characterized and locally served.
- **Visibility and provenance:** The shared repository is public and pinned to an exact reviewed commit. Store publishes no moving branch or alternate product/media source of truth.
- **Rollback:** Reverting the Store submodule pointer and its narrow adapter changes restores the prior implementation without changing another consumer or mutating production data.
