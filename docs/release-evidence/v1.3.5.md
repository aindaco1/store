# Store v1.3.5 release evidence

Date: 2026-08-27

- Candidate branch: `release/v1.3.5-admin-invite-preview`.
- Scope: direct new-admin invitations, post-event mission editor consistency,
  sandboxed preview response isolation, and explicit Podman connection support.
- Previous independently reversible release: `v1.3.4`.
- Shared dependency: Dust Wave Platform `v0.34.1` at
  `ae380c43a16af352ae946f47dd1b7aa4e5b093f0`.

## Behavior and security contract

- A super-admin user save creates the new admin record before sending a
  localized notification with the standard 15-minute, one-time login token.
  Redemption opens Orders directly and rechecks the current admin list, so
  removing the invited user invalidates an unused link. Expired links return to
  the normal email sign-in flow.
- The English and Spanish post-event mission editors use the same fixed height
  with internal scrolling. Link formatting uses the existing chain-link SVG and
  retains an accessible `Link` name. Contenteditable editors use
  `aria-labelledby` instead of an invalid HTML `label[for]` relationship.
- The sandboxed email preview remains script-isolated and moves from `/assets/`
  to `/admin/email-preview-frame/`. It therefore inherits the existing
  path-scoped `private, no-store, no-transform` Cloudflare policy, preventing
  Rocket Loader or Web Analytics injection into an opaque-origin frame.
- An explicit `CONTAINER_CONNECTION` is authoritative for Store's Podman doctor,
  development, and pre-merge wrappers. Those paths never start or restart the
  default VM while another connection is selected, and the selected engine must
  still satisfy the strict release resource gate.

## Candidate verification

- JavaScript and shell syntax, localization completeness, production Jekyll
  build, generated preview routing, and `git diff --check` passed.
- The complete unit suite passed 502 tests across 103 files. Focused Podman,
  Cloudflare response-rule, invitation, authentication, and email coverage
  passed.
- Focused Chromium admin coverage passed the mission-editor icon, accessible
  label, equal-height overflow, and `/admin/email-preview-frame/` route checks.
- The selected external Podman engine passed connectivity, rootless, and basic
  container checks, but exposes about 3.8 GiB rather than the 6 GiB release
  baseline. The local full wrapper therefore remained correctly blocked; the
  protected **Merge Smoke** on the exact candidate is the release-authoritative
  container gate.

## Ethical review

- The invitation is a short-lived bearer link, so forwarding an unused email
  can still delegate access until redemption or expiry. The existing one-time
  nonce, 15-minute lifetime, current-role recheck, audit trail, CSRF-protected
  creation, and removable user record bound that risk without adding passwords
  or a second identity system.
- The preview change reduces third-party script execution and telemetry inside
  a private authoring surface. It does not weaken the iframe sandbox or broaden
  public caching.
- No customer data, payment, catalog, inventory, fulfillment, or public signup
  behavior changes in this release.

## Release sequence

1. Push the candidate branch and require protected **Merge Smoke** on the exact
   commit.
2. Merge the reviewed candidate to `main`, create immutable tag `v1.3.5`, and
   dispatch **Deploy Production** with that tag.
3. Verify the deployed Worker version, preview route, admin response policy,
   public asset markers, and production posture.
4. If acceptance fails, redeploy immutable tag `v1.3.4`; do not roll back
   canonical orders, fulfillment, inventory, or email delivery state.
