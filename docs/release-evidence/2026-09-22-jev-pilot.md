## Scope and shared ownership

The opt-in pilot checks six customer-message surfaces in English and Spanish:
conditional order lookup, pending payment, reminder consent, lookup email,
abandoned-checkout email, and free RSVP confirmation email. Store uses its
existing translator and email payload capture with fixed synthetic inputs.
No customer email was sent, no payment/provider state was changed, and no
customer records or RSVP answers were loaded.

Request construction, bounded Cloudflare transport, result validation, review
decisions and batch execution come from Platform's `test-core/jev` entry.
Store retains its cases, credential discovery, request budget and report logic.
There is no sibling-project import or copied Jev client in Store.

## Live result

The pilot used the existing CutNotes Cloudflare account, supplied only through
the process environment, and existing Wrangler authentication. No token or
account identifier was copied into committed configuration or evidence.

| --- | --- |
| Model | `jev-1.13.0` |
| Requests / questions | 30 / 44 |
| Known-answer controls | 18/18 correct; zero false passes, false failures or reviews |
| Actual message cases | 11/12 pass; one review; zero definite failures |
| Token usage reported by provider | 16,691 input; 1,784 output |
| Pilot exit | 1, review required |

The flagged case is Spanish reminder consent. English says **“Email me one
reminder if I leave checkout.”** Spanish says **“Envíame un recordatorio si no
termino la compra.”** The Spanish text omits the explicit email channel. The
retained meaning-comparison answer returned pass `0.45`, fail `0.54`, uncertain
`0.01`; its `0.09` margin correctly routes to review under the provisional
`0.10` policy. The initial run instead favored pass (`0.52` versus `0.47`) but
also routed to review. The raw leading choice varied while the review outcome
remained stable.
The separate single-reminder requirement passed.

This is a wording question for human review, not a confirmed localization defect:
surrounding UI context may make the channel clear. Neither customer copy nor the
question/policy was changed to make this run green. These small engineering-labeled
controls do not establish general judge reliability or native-speaker approval.

`jev-results/store-pilot-2026-09-22/`: requests, incremental progress,
